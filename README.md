# KridaZone – Sports Accessories Management System

## Overview
KridaZone is a full-stack e-commerce platform designed for buying and selling sports accessories. The system supports multiple user roles including Admin, Seller, and Customer.

The platform allows sellers to list products, customers to browse and purchase items, and administrators to manage system operations.

## Features

### Customer
- Browse sports products
- Add products to cart
- Place orders
- View order history

### Seller
- Add and manage products
- Update product inventory
- Manage orders

### Admin
- Manage users
- Manage products
- Monitor system activity

## System Architecture

Frontend → ReactJS  
Backend → Spring Boot / .NET Web API
Database → MySQL

## Key Functionalities
- User authentication and role-based access control
- Product management system
- Order management
- REST API integration
- Responsive web interface
